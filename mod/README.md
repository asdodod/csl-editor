# Saber Workshop

Отдельный игровой редактор мечей для **Beat Saber 1.40.8 PC**, версия **0.2.1 alpha**. Откройте **Solo → Mods** рядом с Base Game → **Saber Workshop → Open editor**. Интерфейс английский. Open editor открывает широкую мировую панель в текущем меню Solo: проект/детали, форма, предпросмотр, материалы и текстуры видны одновременно. В отдельный экран меню редактор не переводит. Верхняя ручка перемещает стену, Recenter возвращает её перед игроком, Close закрывает. Для работы самого редактора CSL и VainSabers не требуются.

## Установка

Установите BSIPA, SiraUtil 3.2+, BeatSaberMarkupLanguage 1.12+ и AssetBundleLoadingTools 1.1+. Распакуйте ZIP в корень игры: DLL должна попасть в `Plugins`. После замены DLL перезапустите игру.

Для кнопки **Export CSL** дополнительно нужен локальный Python-помощник. Инструкция находится в [exporter/README.md](exporter/README.md); в ZIP это папка ExporterSetup. Одна DLL без настройки помощника экспорт не выполняет.

## Как создать меч без 3D-моделирования

1. **New saber** создаёт Flux: рукоять, три сегмента клинка и кольцо. **+ Blade** и **+ Handle** добавляют готовые формы.
2. Выберите деталь в списке слева. Панель **Shape** меняет её положение, поворот, длину и сечения. Радиус и смещение сечения позволяют изменить форму. **+ Profile**, **+ Ring**, **+ Inner**, Copy и Show / hide управляют деталями. Копирование доступно для созданных профилей; исходные меши можно скрывать и перемещать.
3. **Material → New material** создаёт материал выбранного шейдера и назначает его текущему слою. Duplicate копирует материал вместе с 2D-текстурами. Есть Color, Glow, имя и Use player color. **Advanced** открывает объявленные параметры шейдера с их исходными именами.
4. **Textures / View** выбирает слой и слот текстуры. Положите PNG/JPG в `UserData/SaberWorkshop/Textures`, нажмите Refresh images и Apply image. Generate plasma создаёт бесшовную маску. Изображения встраиваются в проект; доступны повторение и смещение UV.
5. Нижняя часть **Textures / View** меняет общий размер меча, масштаб предпросмотра и цвета рук. Предпросмотр использует игровой рендер и игровой bloom.
6. **Save** сохраняет редактируемый `.workshop.json`. **Use in game** включает проект на следующей одиночной карте. **Export CSL** создаёт отдельный `.saber` в `CustomSabers/Workshop`, который можно выбрать в CSL без Workshop.

Undo/Redo хранит до 16 состояний редактирования в текущем сеансе. История не переносит загрузку между разными исходными файлами. Имя детали в исходной модели хранится отдельно, чтобы не ломать пути анимаций.

## Импорт и сохранение

Левая панель открывает `.saber` из CustomSabers и подпапок через Unity. Исходные меши, материалы, Animator и ParticleSystem сохраняются; legacy-шейдеры обрабатывает AssetBundleLoadingTools. Оригиналы не перезаписываются. Проект проверяет SHA-256 исходника и зависимостей шейдеров. Для переноса импортированного проекта нужен тот же исходный файл; картинки уже находятся в JSON.

Повреждённые контейнеры и неизвестные зависимости могут не загружаться. Предоставленный Cyber Katana не распаковывается ни Unity, ни UnityPy; это не решается настройкой материала.

## Текущие границы

Это alpha, а не полный Unity Editor. Пока нет произвольного редактирования вершин, Shader Graph/HLSL-компиляции, редактора ключей анимации, градиентов по сечениям и конструктора trails/hit events. Специальные эффекты, зависящие от событий CSL, могут отличаться при запуске самого проекта через Workshop. В экспортированном исходном bundle существующие компоненты сохраняются.

Экспорт требует, чтобы выбранные compiled shaders уже находились в исходном bundle либо локальном BaseBundle для новой конструкции. Шейдеры из разных `.saber` автоматически не объединяются. Текущий проект и Use in game после перезапуска выбираются вручную. Мультиплеер не поддержан; другие моды мечей могут конкурировать за замену модели.

## Проверка и сборка

Сборка использует установленные игровые DLL, они не включены в репозиторий или релиз:

```powershell
./mod/build.ps1 -BeatSaberDir 'C:/Games/Beat Saber'
python ./mod/tests/test_contracts.py
./mod/tests/test-installed-bsml.ps1 -BeatSaberDir 'C:/Games/Beat Saber'
```

Проверены контракты BSML и разбор его значений установленной библиотекой. Unity-harness выполняет импорт трёх моделей, изоляцию правок материалов, сохранение/загрузку текстур и UV, создание профилей, цвета рук и ориентацию игровой модели. Отдельная проверка загружает экспортированные Flux, Zoog, MK1 TEK и Batonblade через Unity AssetBundle и проверяет активные меши. Проверка нового интерфейса в VR остаётся необходимой.

Legacy-компоненты `.saber` взяты из [SabersCore](https://github.com/qqrz997/SabersCore) по MIT; уведомление сохранено в `Legacy/LICENSE`. Редактор профилей написан отдельно. Интерфейс [VainSabers](https://github.com/Vainstains/VainSabers) изучен как ориентир; его код в проект не включён.
