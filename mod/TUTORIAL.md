# Saber Workshop tutorial

Open **Solo → Mods → Saber Workshop → Open editor**. Press **Help** in the toolbar for the same seven-step guide. **Show me** opens the relevant section.

## 1. Create a preset

Press **New**, enter a name and choose **Straight** for a simple blade and handle. Press **Create**.

**Segmented** starts with several blade sections; **Empty** starts with no parts.

## 2. Build from parts

The list on the left contains your parts. Click one to edit it.

**Add part** creates a Blade, Handle, Ring, Particles or Trail. **Duplicate** copies the selected part in place. **Hide / show** changes visibility; **Delete** removes it.

## 3. Resize and move

In **Part**, drag **Height**, **Width** or **Depth** to change size in millimetres. A short tap opens the numeric keypad.

Expand **Position and rotation** to place it. The preview starts at actual game size. **Center** resets its position. **View** opens zoom, reference mesh and test swing. **Actual size** restores 1:1 scale. The reference mesh is not exported.

## 4. Make a material

Open **Effects**. Choose a 2D texture, flowing plasma or 3D space. Edit the draft while watching the material card.

Choose a sample shape and a target under **Apply material to**, then press **Apply to part**. Until then the saber stays as it was. **Save effect** adds the draft to your library. Check final bloom on the actual saber.

## 5. Create an outline

Select a solid part. Expand **Outline and shape details** and press **Create outline pair**. This creates a larger dark inverted shell and a smaller coloured inner part.

Select either part on the left and adjust its dimensions and colour independently. **Inverted faces** changes which side of a surface is visible.

## 6. Trails and particles

Use **Add part** to add a Trail or Particles.

For a trail, **Width** controls thickness, **Fade time** how long it stays in the air, and **Tail width** its taper. No texture files are required. Open **View** and turn on **Test swing**.

For particles, start with Sparks, Mist or Dust, then adjust rate, lifetime, speed and size.

## 7. Save and use

**Save** stores the editable Workshop preset. **Open** loads presets or saves a copy. **Undo** and **Redo** restore project edits.

**View > Use preset in game** enables it for the next map. **Export CSL** builds a .saber under CustomSabers/Workshop. Export needs the configured Python and Unity Editor. Exporting edits to imported .saber files is currently paused.
