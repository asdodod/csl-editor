# Saber Workshop — отдельный мод Beat Saber

Игровой редактор мечей для **Beat Saber 1.40.8 PC**. Работает самостоятельно: CustomSabersLite и VainSabers не нужны. Интерфейс находится в **Options → Mod Settings → Saber Workshop**.

Это первая сборка **0.1.0 alpha**. DLL собрана с библиотеками Beat Saber 1.40.8; проверка в пользовательском VR-сеансе ещё требуется.

## Установка

Установите BSIPA, SiraUtil 3.2+, BeatSaberMarkupLanguage 1.12+ и AssetBundleLoadingTools 1.1+. Распакуйте ZIP в корень Beat Saber, чтобы `SaberWorkshop.dll` оказался в `Plugins`. Перезапустите игру после установки.

## Создание

1. Откройте Saber Workshop и нажмите **Новый меч**. Появится Flux с рукоятью, кольцом и тремя сегментами.
2. **Детали и форма** → выберите деталь. Меняйте длину, положение и сечения. Положение сечения задаётся в процентах длины, радиус — в миллиметрах. Можно добавлять профиль, кольцо и внутренний профиль для созданной детали.
3. **Материалы и шейдеры** → выберите деталь, слой и готовый загруженный шейдер. Простой режим показывает основные параметры; расширенный — остальные объявленные свойства с названиями и исходными ключами.
4. **Текстуры внутренних слоёв** → выберите слой и слот. Положите PNG/JPG в `UserData/SaberWorkshop/Textures`, обновите файлы и примените картинку. Настройте повтор и смещение. Изображение встраивается в сохранённый проект.
5. **Сохранить** создаёт `UserData/SaberWorkshop/Projects/<название>.workshop.json`. Включите **Использовать в игре**, чтобы запустить следующую карту с вашей моделью.

## Готовые .saber

В разделе **Открыть меч / проект** видны `.saber` из `CustomSabers` и подпапок. Загрузка выполняется Unity, без ограниченного браузерного распаковщика. Доступны исходные меши, слои материалов и текстуры. Анимации Animator и системы частиц остаются в модели. Legacy-шейдеры проходят через AssetBundleLoadingTools, как у других современных модов мечей.

Это не гарантия загрузки любого файла: повреждённые контейнеры, отсутствующие нестандартные компоненты или неподдерживаемые шейдеры требуют исправления исходника. Например, предоставленный Cyber Katana не распаковывается самой Unity.

## Что сохраняется

Проект хранит правки отдельно от исходного `.saber`, проверяет его SHA-256 и не изменяет оригинал. Для переноса проекта на другой ПК нужна такая же исходная модель в `CustomSabers`; картинки уже встроены в JSON. Новые конструкции не требуют исходного `.saber`.

Экспорт нового Unity AssetBundle `.saber` из запущенной игры не реализован: Unity Player не предоставляет сборщик AssetBundle. Созданный проект запускается самим Saber Workshop. Это не JSON VainSabers и не файл для CSL без этого мода.

## Ограничения alpha

- Редактируются готовые шейдеры и их свойства. Компиляция произвольного HLSL/Shader Graph требует Unity Editor.
- Редактор не подменяет игровой bloom — используется настоящий игровой рендер.
- Геометрия исходных моделей редактируется трансформациями; изменение отдельных вершин и импорт OBJ пока отсутствуют.
- Градиенты сечений, кадровые атласы и motion blur уровня VainSabers пока не реализованы.
- Пользовательские `CustomTrail` и события попаданий пока не воспроизводятся отдельным движком. Native Animator/ParticleSystem сохраняются; специальные эффекты, зависящие от событий другого мода, могут отличаться.
- Состояние текущего проекта и переключатель игровой замены пока восстанавливаются вручную через **Открыть проект** после перезапуска.
- Несколько модов моделей мечей могут конкурировать; переключатель Workshop регистрирует его модель с приоритетом 1000 только для обычного одиночного режима. Мультиплеер пока не поддержан.

## Сборка

Нужны .NET SDK и установленная модифицированная игра с зависимостями:

```powershell
./mod/build.ps1 -BeatSaberDir 'C:/Games/Beat Saber'
python ./mod/tests/test_contracts.py
```

Игровые DLL не входят в репозиторий и релиз. Legacy-компоненты формата `.saber` взяты из [SabersCore](https://github.com/qqrz997/SabersCore) по MIT, уведомление сохранено в `Legacy/LICENSE`. Система профилей написана отдельно; исходники VainSabers не включены.
